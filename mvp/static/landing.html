Connect to your Claude and Codex

Atelier Sim: simulated users for any web page or app, from your own agent. No token needed.

Claude Code

Plugin

/plugin marketplace add ShreyasPatel031/UserSim@claude/usersim-plugin
/plugin install atelier-sim@atelier-sim

or the MCP server only

claude mcp add --transport http atelier-sim https://atelier-sim.com/mcp

Claude Desktop

{
  "mcpServers": {
    "atelier-sim": { "command": "npx", "args": ["-y", "mcp-remote", "https://atelier-sim.com/mcp"] }
  }
}

Codex

# ~/.codex/config.toml
[mcp_servers.atelier-sim]
