
## Scope note (explanation audit, Nov 14)
These drivers explain **arm 2** (tree-SHAP on arm 2's own boosters). The pick-level figures (fidelity, agreement with the readable stumps) are on the 214-day arm-2 backtest. On a fallback night (arm 2 missing, e.g. Nov 14) the published order is clean_nosite, and these drivers do not describe it. The published per-launch driver files (results/web/why/<d>_0005.json) are written by PH ops' why_drivers.py, not by this report.
