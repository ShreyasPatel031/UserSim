# Cohort scorecard results (aggregates only)

- `cohort_scorecard.v1.json`: combined backtest scorecard (WHO, WHAT, north-star status). Versions are kept; `history.jsonl` lists them.
- `who_frozen_backtest*.json`: frozen backer lists and explain groups (Nov 8-20) vs re-read real backers. P1 explain, P2 CF list, P4 launch-specific, P5 plain top 200.
- `who_topic_backtest.json`: P3 topic-neighbour mix on backtest_v1 (Oct 22-Nov 20).
- `vote_likelihood.json`, `sentiment_backtest.json`: PREREG addendum metrics.

Numbers are [mean, day-bootstrap 2.5%, 97.5%, launches, days].
