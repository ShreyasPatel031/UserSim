# Online-Mind2Web (OM2W) task data

Canonical live eval set for this repo: **300 tasks / ~145 hosts**.

| File | Role |
|------|------|
| `online_mind2web.jsonl` | Public mirror from OpenWebRL (official HF dataset is **gated**) |
| `om2w_tasks.json` | Harness-normalized tasks (`eval_index` 0–299) |

Official source (request access): https://huggingface.co/datasets/osunlp/Online-Mind2Web

Old offline dump archived at `data/_archived_mind2web_tasks.json` — **do not use for live eval**.
