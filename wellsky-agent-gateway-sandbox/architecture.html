What it took beyond the docs

  • Token sharing turned on, which disables Agent Identity's token binding. Without it, every model call through the gateway fails with 401.
  • A separate invoker service account, because Agent Identity can't mint a Cloud Run ID token by itself.
  • 13 Google API endpoints registered before enforcement would let the agent's own model and telemetry calls through.
  • A healthcare DLP template. Model Armor's basic setup missed MRN, DOB and diagnosis.
  • MCP registry entries that use the exact URL the agent calls. Cloud Run's legacy URL showed up as unregistered.
