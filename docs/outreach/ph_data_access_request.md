# Draft: request to Product Hunt for data access (for Shreyas to send)

To: Product Hunt partnerships / API team (api@producthunt.com or the developer contact on the API page)
From: Shreyas Patel, UserSim

Subject: Research data access: public upvote and follow activity

Hi Product Hunt team,

We're building UserSim, a research project that models how real people respond to product launches, so makers can test a launch before it goes live. Product Hunt is our main test bed: we forecast which launches reach the top of the daily leaderboard.

We use the public GraphQL API (developer token) for launches, votes and comments. What the public API doesn't expose, and what our model most needs, is user-level activity: which launches a user has upvoted, and whom they follow. We'd like to ask for one of:

1. A higher-rate or research API tier that includes user upvotes and follows (read-only), or
2. A periodic data export, anonymized if you prefer: hashed user ids are fine for us, or
3. A data partnership in which we share our launch-forecast results with your team.

We're happy to sign terms that limit use to research, never redistribute personal data, and delete on request. We'd also share what we learn about launch dynamics.

Can we set up a short call?

Thanks,
Shreyas
