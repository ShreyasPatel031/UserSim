# UserSim plugin for Claude Code

This branch holds only the UserSim Claude Code plugin and its marketplace file. The plugin is in
[`plugins/usersim`](plugins/usersim); its README explains what it does, what it sends and how to use it.

Install:

```
/plugin marketplace add ShreyasPatel031/UserSim@claude/usersim-plugin
/plugin install usersim@usersim
```
