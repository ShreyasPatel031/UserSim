# Atelier Sim plugin for Claude Code

This branch holds only the Atelier Sim Claude Code plugin and its marketplace file. The plugin is in
[`plugins/atelier-sim`](plugins/atelier-sim); its README explains what it does, what it sends and how to use it.

Install:

```
/plugin marketplace add ShreyasPatel031/UserSim@atelier-sim-release
/plugin install atelier-sim@atelier-sim
```
